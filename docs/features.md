## 🚀 Key Features

* 📡 **Real-Time Monitoring**
  Continuously tracks pH, TDS, and temperature

* ⚙️ **Automated Water Regulation**
  Automatically drains and refills water based on sensor data

* 🌐 **Remote Monitoring**
  Access live data through cloud dashboard (Blynk)

* 🔄 **Smart Control System**
  Uses ESP32 and ESP-NOW for fast and reliable communication

* 💧 **Water Quality Management**
  Maintains stable conditions for optimal pearl growth

* ⚡ **Low Power & Cost Efficient**
  Designed using affordable and energy-efficient components

* 📊 **Data-Driven Operation**
  Enables better decision-making through continuous data collection

* 🧠 **Scalable Architecture**
  Can be extended to multiple tanks and larger farms
